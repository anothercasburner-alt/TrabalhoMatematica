Resumo de funções

Função: cada entrada x tem exatamente uma saída f(x).

Linear: f(x) = ax + b
Quadrática: f(x) = ax² + bx + c, Δ = b² − 4ac
Exponencial: f(x) = aˣ
Logaritmo: loga(b) = c ⇔ aᶜ = b
Fórmulas de geometria
Retângulo: A = b × h
Triângulo: A = (b × h) / 2
Círculo: A = πr², C = 2πr
Cilindro: V = πr²h
Esfera: V = (4/3)πr³

tg θ = cateto oposto / cateto adjacente
