Funções

Acordeão

Uma função é uma regra que associa a cada entrada x exatamente uma saída f(x). O conjunto das entradas é o domínio e o conjunto das saídas é a imagem.

f(x) = ax + b
O gráfico é uma reta. a é o coeficiente angular (o quanto a reta é inclinada) e b é o ponto onde a reta cruza o eixo y. Se a > 0, a função é crescente; se a < 0, é decrescente.

f(x) = ax² + bx + c   |   x = (−b ± √Δ) / 2a,  Δ = b² − 4ac
O gráfico é uma parábola. Se a > 0, a concavidade é voltada para cima; se a < 0, é voltada para baixo. O vértice está em x = −b / 2a.

f(x) = aˣ   |   loga(b) = c ⇔ aᶜ = b
As funções exponenciais modelam crescimento ou decaimento rápido (populações, juros). O logaritmo é a função inversa da exponencial.

Probabilidade

Lista

A probabilidade mede a chance de um evento acontecer, em uma escala de 0 (impossível) a 1 (certo).

  • Regra básica: P(A) = casos favoráveis / casos possíveis
  • Complementar: P(não A) = 1 − P(A)
  • Eventos independentes: P(A e B) = P(A) × P(B)
  • Um evento ou outro: P(A ou B) = P(A) + P(B) − P(A e B)
Exemplo: a probabilidade de tirar 6 em um dado é 1/6 ≈ 16,7%.

Matemática Financeira

Cartões

A matemática financeira nos ajuda a entender porcentagens, descontos, juros e empréstimos.

Juros simples

J = C · i · t    M = C + J

Os juros são sempre calculados sobre o valor original.

Juros compostos

M = C · (1 + i)t

Os juros são incorporados ao montante, então juros rendem juros.

C = capital, i = taxa por período, t = tempo, M = montante. Um desconto de 20% sobre R$ 50: 50 × 0,8 = R$ 40.
